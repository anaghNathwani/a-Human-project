##What is Aurora? From our donor
Aurora is a website that takes a fantastic new approach to web development: One page, multiple sections. Although there is only one HTML page, it serves the function that is required to bring users closer in the world of web design. Aurora is not actively accepting clients at this moment, but is a place where clients can request websites tailored to them. Although AI can do this easily, the goal of Aurora is to combat AI taking over the software industry, and this is starting with a no-AI place where developers can help new members of the industry, and people who just want a portfolio. Embracing a similar philosophy as _Controlled Chaos_ in that the website is completly JavaScript free!
