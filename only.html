CSS-ONLY MINDSET

The holy grail of web developement programming languages is often attributed to HTML, CSS, and JavaScript. While each of these languages provides both strengths and weaknesses, developers and artists alike often find themselves relying on all 3 of them.

Many developers start by learning HTML and CSS, only to quickly realize that their potential is very limited, even if they want to prioritize front-end developement. This is where they are quickly introduced ot Javascreipt, which opens up a whole new world of possibilities. However, this also introduces a new set of challenges, as JavaScript can be complex and difficult to learn.

What I have created is a website that seems to use JavaScript when it dosen't. This is an open-source project stored on GitHub, meaning that anyone can see how I accomplished this work. Learn from what I have done, and give me feedback! I am okay with you using AI tools to help you understand how I did this, but please do not use AI to recreate this project. Let's keep this project human-made, and celebrate the creativity that we as humans can achieve without the use of AI tools.

As part of my mission to promote human creativity, I encourage you to donate your work to this project. By contributing your own creations, you help to build a community that values originality and the human touch in web development. Together, we can create something truly special that showcases the best of what we can achieve without relying on AI.
